Keamanan Relay Webhook n8n

Untuk mencegah kebocoran URL Webhook n8n di browser dan melindungi endpoint dari spam, seluruh payload sekarang dikirim melalui proxy server-side (webhook-proxy.php).

✅ URL n8n Tersembunyi: Disimpan aman sebagai konstanta PHP di server.
✅ HMAC-SHA256 Signature: Header X-XXH-Signature + X-XXH-Timestamp (anti-replay 5 menit).
✅ Rate Limiting: Cooldown 60 detik di client + maks 5 req/menit per akun di MySQL.
✅ CORS Ketat: Hanya mengizinkan origin https://xiexehat.page.gd.
